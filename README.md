# KIRo4LeMi Survey

This repository contains the web-based survey application developed for the KIRo4LeMi research project.

The survey investigates how interfaces tailored to a specific user-role compare to generic interfaces. Participants complete multiple simulated robot scenarios, interact with an AI-based chat assistant, and answer standardized questionnaires.

## Technology

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- OpenAI API
- PHP backend for session persistence and logging

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available locally at:

```
http://localhost:3000
```

## Deployment

Production deployments are performed automatically via GitLab CI/CD to Vercel.
